# 발걸음 성과 별첨

한국도로교통공단 강서운전면허시험장 직무개발 동아리 '발걸음' 결과보고서의 QR 별첨 웹페이지.

- 주소: https://opikhg.github.io/balgeoreum/
- 검색 비노출(noindex), QR·링크로만 접속

## 구성

- `index.html` — 페이지 전체 (서막 → 됩니다 → 한눈에 보기 → 길잡이 → 발자국 → 발걸음 → 맺음)
- `img/` — 결과보고서에 실린 결과물 캡처

## 결과물 실행 주소 연결

`index.html` 아래쪽 `APPS` 목록의 `url`을 채우면 해당 결과물의 ▶ 실행 버튼이 켜진다.
`url`이 비어 있으면 버튼은 '주소 연결 예정'으로, 화면 미리보기는 '화면 크게 보기'로 표시된다.

| 이름 | 결과물 | 주소 |
|---|---|---|
| `allinone` | 강서 올인원 | (미연결) |
| `seven` | 7년 무사고 서류 자가진단 | (미연결) |
| `exam` | 응시원서 번역본 | https://opikhg.github.io/exam-form/ |
| `photo` | 여권사진 규격 셀프 체크 | https://opikhg.github.io/photo-self-check/ |
| `game` | 면허 시험장 탐험 | https://opikhg.github.io/license-game/ |

주소 끝에 `#run-game`처럼 붙이면 해당 결과물이 바로 열린 상태로 접속된다.
